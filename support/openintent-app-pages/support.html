System requirement.
iOS 17 or later.
Permission required.
Screen Time authorization is needed for app selection and shielding.

1. Quick Setup

  1. Install and open 有意打开.
  2. Tap the Screen Time authorization button and allow access when iOS asks.
  3. Create a protection group.
  4. Select apps, categories, or web domains to protect.
  5. Tap lock to apply protection. Tap unlock when you intentionally want temporary access.
  6. Optional: use Shortcuts actions to lock or unlock a group by name.

2. Troubleshooting

Screen Time authorization does not appear or fails

  • Confirm that Screen Time is available on the device.
  • Open iOS Settings and review Screen Time restrictions.
  • Quit and reopen 有意打开, then request authorization again.
  • If the device is managed by an organization or family administrator, Screen Time settings may be restricted.

Selected apps are not blocked

  • Confirm that the group contains selected apps, categories, or web domains.
  • Confirm that the group is locked in 有意打开.
  • Wait a few seconds for iOS ManagedSettings to apply the shield.
  • Unlock all groups, then lock the target group again.

Shortcuts action cannot find a group

  • Use the exact group name shown in 有意打开.
  • Open 有意打开 once after editing groups so Shortcuts can see the latest state.
  • Confirm that shortcut lock/unlock actions are allowed for the group.

The shield page button does not enter the app

  • Check the group's shield button entry setting in 有意打开.
  • If entry is disabled, use 有意打开 or Shortcuts to unlock the group first.

Reset local settings

  • Remove or rename groups in the app.
  • Use unlock controls to remove protection before uninstalling.
  • Delete and reinstall the app if you want iOS to remove local app data.

3. Privacy and Data

有意打开 does not use accounts, ads, analytics SDKs, or tracking SDKs. App selection is handled by Apple Screen Time and FamilyControls. Protection groups and Apple-provided system tokens are stored locally on the device so the main app and shield extensions can work.

Read the full privacy policy: 有意打开 Privacy Policy.

4. Report a Bug or Request Help

Open a support request on GitHub Issues:

https://github.com/hereare/hereare.github.io/issues/new

GitHub Issues are public. Do not include private app lists, personal contact information, confidential screenshots, or sensitive family/device details.

Useful details to include

  • Device model and iOS version.
  • 有意打开 app version and build number.
  • Whether Screen Time authorization is granted.
  • What you expected to happen.
  • What actually happened.
  • Steps that reproduce the issue.
